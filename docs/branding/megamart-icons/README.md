# MegaMart icon assets

Extracted from page 2 ("Three mark variants") of **Megamart Branding.pdf**.

## Included marks

- `megamart-mark-primary`: transparent modular mark using Primary Indigo `#4F46E5` and Amber `#F59E0B`.
- `megamart-badge-indigo`: Primary Indigo badge with the mark knocked out in white.
- `megamart-badge-midnight`: one-colour Midnight `#111827` badge with the mark knocked out in white.
- `megamart-favicon`: pixel-aligned 16 px favicon artwork.

Each mark is available as an editable SVG and as transparent PNG files at useful interface sizes. The root `favicon.ico` contains 16 px, 32 px, and 48 px images.

## Recommended use

- Use `megamart-mark-primary.svg` for the normal brand mark on light backgrounds.
- Use `megamart-badge-indigo.svg` where the icon needs a filled edge, such as app tiles and avatars.
- Use `megamart-badge-midnight.svg` for a one-colour reproduction.
- Use `favicon.ico` or the files under `png/favicon/` for browser icons.

SVG is preferred for web and UI layouts. PNG is provided for platforms that require raster images.
