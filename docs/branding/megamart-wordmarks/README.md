# MegaMart wordmark lockups

Extracted as vector artwork from page 2 ("Three mark variants") of **Megamart Branding.pdf**.

## Included lockups

- `megamart-lockup-primary` - recommended modular mark plus the Midnight MegaMart wordmark.
- `megamart-wordmark-two-tone` - text-only indigo/Midnight wordmark with amber accent.
- `megamart-lockup-badge` - filled indigo badge plus the Midnight MegaMart wordmark.
- `megamart-lockup-reversed` - white mark and wordmark in a Midnight container for dark or high-contrast placement.

Each lockup is supplied as an editable, transparent SVG and as transparent PNGs at 512 px, 1024 px, and 2048 px widths.

## Recommended website use

Use the primary SVG in the main navigation:

```html
<img
  src="/assets/brand/megamart-lockup-primary.svg"
  alt="MegaMart"
  width="180"
  height="53"
/>
```

SVG is preferred for the website because it remains sharp at every screen size. Use the PNG versions only where a platform does not accept SVG files. Keep the artwork's original proportions and do not recolor, stretch, or rearrange the icon and wordmark.

The separate favicon and app-icon files remain in the earlier **MegaMart Icon Assets** pack.
